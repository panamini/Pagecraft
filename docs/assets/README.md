# Pagecraft Visual Assets

These files are renamed for clearer GitHub and search-friendly usage.

## Files

- `pagecraft-agent-memory-github-banner.png`
  - Recommended README hero image.
  - Wide banner with logo, product name, and memory/network visual.

- `pagecraft-obsidian-llm-memory-hero.png`
  - Alternative hero image.
  - Strong for social previews, docs pages, or launch posts.

- `pagecraft-logo-transparent-wide.png`
  - Transparent wide logo asset.
  - Useful for compact headers or dark backgrounds.
